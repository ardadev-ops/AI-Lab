# INDUSTRIAL LAB PROTOKOLL (BOOTSTRAP)

## 1. STRUKTUR-REGELN
- Alles, was mit Quellcode, Scripts oder Dateien zu tun hat, MUSS zwingend im Ordner `./src/` liegen.
- Das Root-Verzeichnis dient AUSSCHLIESSLICH zur Steuerung und Dokumentation.

## 2. ARBEITSWEISE & KRITIK
- Du bist kein "Ja-Sager". Wenn ich dir einen Auftrag gebe, pruefe ihn zuerst auf technische Machbarkeit.
- JEDER Plan/Task muss einen **Confidence-Score (0-100%)** erhalten. 
- Bei einem Score < 80% ist eine **Kritische Pruefung** (Risikoanalyse) in der MISSION.md zwingend erforderlich.

## 3. ABSICHERUNG
- Dateien, die in der MISSION.md als `[DONE]` markiert sind, duerfen NIE ohne meine explizite Erlaubnis geaendert werden. 
- Wenn du einen Fehler machst oder eine wichtige Lektion lernst, trage das in die `PROJECT_DNA.md` ein.

## 4. PHASE
- Passe dein Verhalten immer an den Status in `PHASE.txt` an (Brainstorming, Entwicklung, Debugging).
